# H1 光机询价与验收规格

候选面板GZOT VGA020HW02C，首选由供应商交付已贴合、可调焦、带驱动和明确使用许可的**完整透明近眼光机**。本项目没有在零售渠道确认该完整模组的型号/现货/单价，不生成虚构的采购链接。备选ActiveLook/OEM方案改变分辨率、颜色和接口，不能原样替换后沿用预算。

RFQ必须索取：

1. 完整光机型号、可采购数量、MOQ/NRE、交期、单价阶梯、停产通知及替代策略。
2. 固定左眼安装所需出瞳中心、FOV定义、eyebox在明确眼距/亮度下的有效尺寸、18mm eye relief、透过率、屈光/像散兼容策略。
3. 640×480实际可绘制范围、隐藏/裁切区域、刷新/局部更新规则、QSPI电平、时钟、复位、帧格式与可发布的初始化手册。
4. 三路偏置、启动/关闭时序、各亮度下电流、睡眠/唤醒时间、温度与亮度读回方法、掉电安全状态。
5. 机械STEP、质量、包络、公差、清洁/贴合工艺、胶水与镀膜条件、杂散光/鬼影与光生物安全报告、第三方知识产权许可范围。

`specification.json` 的14.3mm理想焦距只是近轴计算，**不是可交给镜片厂磨制的曲面处方**。没有真实镜片材料、非球面参数、表面误差、MTF、入瞳/出瞳或畸变标定。STEP中的绿色方块是18×15×14mm询价包络，不是厂商光机实物模型。

HUD以黑底发光文字为主，不用黑色遮挡面板挡住现实。应在300/1000/10000lux环境，1m、2m及远距离实景背景上测试文字识别、对比、ghost、漏光、眼盒边缘裁切和动态闪烁。分光亮度预算不能代替校准辐射测量。未通过前不声称适合室外长期使用。
