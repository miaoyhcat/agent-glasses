# 当前原型操作手册

当前使用入口是桌面工作台与Android调试应用；没有可交付的完整实体眼镜。先按README跑模拟器，再考虑接D0。

电脑只注册你愿意交给智能体处理的项目目录。手机核对证书后配对；不要把operator令牌当手机令牌。选择电脑地址对应的设备、项目和动作，说完检查转写再点发送。电脑看到完整指令后批准，HUD显示等待、准备、运行、取消中或结果；unknown需要回电脑检查，不能理解为完成。

inspect完成后勾选继续最近完成任务，再发“修复发现的问题”。授权副本写入后，修复只保存在同一副本；继续发test运行已有测试。原项目要由电脑人工比较和合入。没有自动发布代码、向别人发送内容或让眼镜直接操作任意宿主路径的入口。

D0拍照前须开物理许可开关；拍摄状态灯应在现实中清楚可见。短按BOOT可离线拍照，未传媒体留在眼镜；没有确认接收前不要清缓存。手机选择同步媒体后会校验并落盘；电脑上传是另一步，失败可续传。格式化缓存会删除媒体，只在确认可清空时操作。

AI语音/图像分析需电脑端显式启用，并在手机再次同意上传及可能费用。转写文本不会自动下发给Codex。手机TTS直接朗读；眼镜短语音是实验缓存播放，需等待传输、最长8秒，当前不具备已验证的自然实时对话体验。

通知转发默认为空，系统授权后仍需选择应用。只显示标题仍可能暴露隐私，使用者决定哪些应用适合显示。当前手机切后台停止任务轮询；原型不承诺全天后台连接。

不要把D0台架当成可在户外、驾驶、运动或长时间佩戴时使用的成品。H1的热、光、电池和佩戴验证尚未完成；相应实验按验收矩阵执行。
