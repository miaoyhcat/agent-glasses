# 工程可行性与敏感性

所有复算输入均为仓库文件，运行 `python scripts/engineering.py`。结果在 `docs/evidence/engineering-results.json`。计算验证公式与预算自洽，不把未知光机功耗或预测质量转变为测量结果。

## 候选架构选择

三条候选路线及全部主观评分见 `architecture-candidates.json`。权重为：功能20%、采购20%、质量15%、能量15%、开放性15%、制造10%、舒适5%，每项1–5分。评分只用于解释研发取舍，不是市场产品性能排名。

H1 的软件与普通外设较易取得，但完整光机仍需供应商配合。独立Android AR SoC路线增加BSP/NDA、封装、热和电池门槛。购买完整Halo可较早尝试近眼HUD，但未证明本项目要求的持久离线录像与完整制造资料，因此不能据其轻量优势宣布满足全部要求。

`architecture-ranking.json` 分别改变能量和采购权重并重归一化其他权重。完整平台可能在原始评分上高于H1；**所有候选都有未关闭的硬门槛，没有方案获得“可投产”结论**。H1是为了继续实现完整功能而选定的研发方向；C路线是更早验证HUD交互的辅助入口。

## 质量与受力

完整质量预算约 **66.45g**，合理性区间是独立分项上下界，不能作为统计置信区间；所有分项同时达到最低值尤其不可信。电池为三枚GRP1654M1，共8.85g供应商标称裸电芯质量，保护板、NTC、焊片另外计入；处方片也已计入。约50g要求目前没有被满足，不能由市场某产品49g推出我们的设计同样轻。

早期恒截面镜腿的CAD体积与质量预算不符，已改成65mm电子仓+较细耳后段；镜腿与盖板的几何质量约每侧6.83g（按PA12 1.01g/cm³假设），预算提高到每侧7.2g。光机移到左侧，与右侧MCU/摄像头配重。`mass-placement.json` 给出集中质量坐标、鼻梁/耳部简化静力估算。当前模型鼻梁约承担0.525N、约81%的竖向重量，尚不能接受为长时舒适设计；后续必须通过断电试戴比较后移电池/加长电子仓等方案，重做结构质量与强度预算。该模型忽略夹持力、皮肤形状、动作和摩擦，不证明舒适，且CAD铰链/镜片固定还未完成。

## 能量

采用供应商确认的匹配、受保护 **1S3P 450mAh** 电池包作为询价目标，不允许个人直接并接散装电芯。

\[
E_{nom}=3\times0.150\,Ah\times3.7\,V=1.665\,Wh
\]
\[
E_{EOL}=E_{nom}\times0.90\times0.80=1.1988\,Wh,\quad
P_{bat}=P_{rail}/0.88+0.002\,W
\]

0.90为可用能量假设，0.80为寿命末期容量假设。负载功耗按互斥状态统计，避免重复/遗漏转换损耗。

| 负载 | 预计能量时长（EOL） | 限制 |
|---|---:|---|
| 已定义混合 | 8.49h | 73%连接待机、18%HUD、5%语音、1%拍摄、1%录制、2%传输；功耗未测 |
| 重显示混合 | 3.54h | 60%HUD；不能称全天显示 |
| 连续HUD | 4.19h | 假设光机及驱动功耗已包含；未达到8h |
| 连续语音 | 2.02h | 手机/云端能耗另计，D0已编译短语音链；声学/功耗未测 |
| 连续录像 | 1.05h能量上限 | **热预算不支持宣称连续运行到该时长**；D0单段最多15秒 |
| 连续传输 | 1.17h能量上限 | H1 Wi-Fi突发路径尚未实现；D0目前BLE更慢 |
| 连接待机 | 44.4h能量上限 | 不作为真实使用续航宣传，且当前D0不具备此待机功耗 |

敏感性按连接待机功耗×1/2/4、HUD额外0/150/350mW、电池保有容量60%/80%/100%形成情景网格。它不是“达标概率”。如果长期亮屏或待机功耗偏高，8h目标会失效。

三枚电芯按厂商2C标称合计放电能力约0.9A，仍需供应商按并联保护和低温/老化复核。按3.0V低电压和88%转换效率，0.75A设计电流对应约1.98W可用负载；不得让Wi-Fi发送、相机、扬声器和高亮屏任意叠加。H1需要互斥调度、限流和峰值压降试验。TPS63031已从候选中剔除，选用更有峰值余量的TPS63070；输出能力仍须按手册曲线与实测确认。

## 光学

GZOT VGA020HW02C公开面板参数为640×480、6.3µm像素、标称5000nit与100mW典型面板功耗。[S12] 它需要+5.5V、+1.8V、−4.5V；3.3V直接驱动方案无效。H1加入偏置、电源时序和逻辑转换预算，优先完整供应商光机。150mW是全光机路径占用的初步预算假设，尚未证明足够。

4.032×3.024mm有效区与14.3mm理想准直焦距的近轴公式 `2 atan(size/(2f))` 给出约20°对角视场；2m虚像对应物距约14.2mm。±0.1mm轴向偏差会造成明显屈光变化，因此必须有调焦/装调方法。模型没有真实镜片曲率、镀膜、出瞳或MTF，不能声称已做完整光线追迹或证明8×6mm眼盒。5000×0.30×0.65的简化辐亮度预算也不是经过校准的入眼亮度。

## 热

仅做 `T≈Tamb+P×Rθ` 的集中参数敏感性，Rθ取18/35/65K/W，环境取25/35°C。这个范围并非从完整结构实测拟合。连续约1W录像在温暖环境明显可能超过40°C接触目标，因此当前没有连续录像或户外长期使用合格结论。

H1下一阶段必须布置独立电芯NTC与接触面温度测点，先在仿头/隔热支架上测，再制定工作时间与冷却调度。D0没有可验证的皮肤温度闭环；CPU内部温度不能代替接触面温度。未通过前只进行断电佩戴及离体供电试验。
