# 制造与复现指南

**允许复现当前软件和离体台架；不能直接从此仓库向工厂下单制造完整日用眼镜。** 已发布的是D0接线、一个联锁测试coupon和H1布局夹具。H1主板、完整光机、FPC和生产镜架尚未发布。

## 可先做的低风险阶段

1. 运行软件测试/HTTPS模拟，确认数据和权限流程。
2. 购买或准备真实N16R8开发板、3.3V DVP OV2640模块、3.3V逻辑ST7789模块、I2S麦克风/功放、匹配阻抗小扬声器、microSD和限流台式电源；逐项核对模块引脚，不按排针外观猜测。
3. 按`hardware/assembly/d0-wiring.csv`接线。先断开相机和功放，在限流电源上验证3.3V与默认关闭电平，再分别接入。开发板USB和外部电源不得形成未经设计的反向供电。
4. 烧录固件并通过USB物理配钥。先做显示/身份认证，再做离体拍照、缓存、媒体传输、录音、提示音与短语音。所有缓存删除必须能追溯到核验ack。
5. 打印无电池的H1夹具进行鼻梁、镜腿、装配空间与遮挡检查。STL为布局夹具，不是经过强度认证的镜架，不装活电池佩戴。

## 联锁测试coupon

KiCad7源图和板文件：`hardware/schematics/interlock.kicad_sch`、`hardware/pcb/interlock-test-coupon/interlock-test.kicad_pcb`。测试板约66×41mm，双层1.6mm FR-4，目标1oz铜；不用于镜架内安装。焊盘与连接关系由`build_interlock.py`和CSV共同记录。任何Gerber输出均标为工程试验资料，需工程师先审核封装、极性、元件额定值和制造商能力。

MCP6547-I/P为DIP8，TPS22918DBVR为SOT23-6；R/C为自绘0805焊盘；逐件BOM为`hardware/bom/interlock-coupon.csv`。D1需选额定电流与Vf满足窗口的可见绿光器件，不能随意换成约3V的InGaN绿色LED。D1的1脚为K、2脚为A。SW1是外接机械开关端子，不是默认短接。J1仅输入3.3V，不可直接接USB5V或锂电池。

上电100mA限流起步，无相机负载测：SW开/关、REQ高/低、LED开路、LED短路、REQ悬空、输入上下电。验证VCAM在故障时不可维持相机工作电压；接假负载阶跃测上升/放电波形。再验证真实IO不反向供电。后者未实现前，不得宣布完成硬件隐私验收。

当前DRC为0 error、0 unconnected，仍有18项自绘封装未注册外部库的warning。嵌入封装可打开，但仍须独立尺寸/封装审核和本机工程库配置。没有用降低电气间距规则来隐藏错误。KiCad网表比较并不证明模拟电路在温度、公差和故障下正确。

## H1投板前硬门槛

完整光机采购与初始化资料、电池包批准、整机原理图ERC、引脚资源、三轨时序、掉电IO隔离、硬件默认充电限流/NTC、主板DRC、供应商堆叠、DFM和电源/射频布局必须全部关闭。D0的跳线图不能当作主板制造输出。

主板拟4层连续参考地，实际层厚与材料由板厂给出。USB全速差分先按90Ω目标协商堆叠，不能把通用线宽当所有板厂的阻抗解。DVP相机留在右镜腿前端短距离，光机QSPI跨框需短线、地参考、源端串阻和实际边沿/眼图检查。活动铰链主要承载低速、电源及受控显示链，不把未经验证的长DVP跳线装进铰链。

天线前方禁止电池、金属铰链/镀层、地铜和人体贴近造成的任意覆盖；尺寸按模块指南及实机VNA/辐射测试确定。FPC中性层、最小动态弯折半径、应变释放和循环寿命须与供应商确认；当前没有发布可投产FPC。

## 结构工艺与量产

前期PA12/MJF或精细打印用于断电几何迭代，光机基准面可用机加工夹具验证。塑胶整体公差、光学安装基准和调焦公差不同：不能要求普通打印镜架自动达到±0.03mm光学基准。预留调焦/出瞳位置调整并用仪器标定后锁定。

还缺完整可折叠铰链、Rx片保持结构、音腔/防汗膜、密封、维修、胶水和强度定版。未经跌落、汗液、充电循环、温度、连接耐久和抽样良率试验，不发布IP等级、寿命或量产良率。成本表是研发预算区间，未取得完整光机与电池包报价，不能当成工厂成交BOM。
