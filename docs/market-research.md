# 市场与技术调研结论

检索基准：2026-10-16（北京时间）。完整字段在 [JSON](market-database.json) / [CSV](market-database.csv)，来源在 [sources.md](sources.md)。`null` 或“未确认”表示本次没有足够一手证据，不以相近型号填空。价格是特定地区网页快照，不代表成交价、现货或全球统一定价。

## 对设计有决定性影响的比较

| 路线 / 产品 | 可核实优势 | 对 AgentGlass 的限制 |
|---|---|---|
| Rokid Glasses | 官方49g、双目MicroLED、12MP、音频与32GB存储，说明高集成消费产品可以接近50g [S03] | 完整芯片BSP/光机/任意HUD控制不等于个人可采购；不能把厂商工程成果当作我们的复现能力 |
| Meta Display / Gen3 | 成熟拍摄和音频；Display 有镜片屏，Gen3是无显示产品 [S01,S02] | “有摄像头的AI眼镜”和“能显示自定义任务状态的开发平台”是不同条件 |
| Even G2 | 36g级、双目绿光、官方IP65、192mAh [S04,S43] | 无摄像头和扬声器；两天regular use不能与连续语音/录像比较 |
| Halo / Frame | 开放Lua/BLE；Halo有麦克风、骨传导和低功耗视觉 [S05,S25,S34] | Halo面板640×480但可绘图区256×256；Frame的640×400/20°不能混用；完整离线媒体可靠性仍需验证 |
| ENGO2 / ActiveLook | 轻量运动HUD、公开BLE图元接口 [S08,S26] | 没有完整相机/语音/本地媒体链；1mW面板宣传不等于整机功耗 |
| MiRZA / Epson | 日本分体XR与成熟工业装配经验 [S07,S09] | 分体计算仍有配对设备、线缆、系统重量和功耗；不直接适合普通日常镜架 |
| XREAL One Pro / AURA | 大FOV、外部计算与成熟显示体验 [S10,S46] | 光学外形、外部主机和供电不同；M2P延迟不能代替语音/网络/智能体端到端延迟 |
| RayNeo X3 Pro | 76±1g、AR1、双目640×480全彩MicroLED和12MP，具备开发者模式 [S27] | 高集成完整独立方案仍较重；亮度/充电数字是厂商值，未验证其BSP/光机可采购 |
| Snap SPECS | 2026已展示完整独立空间AR [S14] | 132/136g的厂商质量级别与轻量HUD目标不同；预售不等于交付验收 |
| Vuzix Z100 | 38g级、低功耗透明HUD和手机SDK [S45] | 历史发布价/48h宣传不能视为当日现货与同负载续航；集成拍摄和音频须重做预算 |
| T-Glass V3 | 公开引脚、电路、相机和音频例程 [S06] | 可视区域只有126×126；零售状态未确认；文档充电复位默认电流风险必须由硬件限制解决 |

在日常完整消费功能、可编程性、空间AR能力三个维度上，没有一个可证明的单一“全球最强”。Rokid/Meta适合学习高集成消费体验，Halo更适合快速自定义实验，工业/空间产品适合参考分体架构。本项目不采用主观榜单作为器件选型依据。

## 资料冲突与独立体验

Halo 当前商品页为399美元，早期发布稿299美元不是当前报价；商品页还同时含有开始出货/即将出货措辞，不能因此承诺即时可交付。硬件手册、Lua API和商店“完全公开”宣传也不能代替逐一确认实际可下载的完整制造文件。[S05,S24,S34]

Rokid 当前美国商店展示999美元，而历史长评引用过更低售价；不能把两个时间/渠道价格合并。其网页相机焦距存在可疑单位，未将该字段用于光学计算。[S03,S29] Even G2 独立报道与厂商防护等级有冲突，本项目记录官方IP65，不自行提升。[S04,S30]

原始独立使用报道对 Meta Display 的重量、混合续航提出限制；Rokid 长期使用报道肯定轻巧与取景，同时指出弱光/手机体验问题；Even 报道肯定硬件但指出软件稳定性。这些是原作者使用体验，不是本项目测试，也未把不同负载的结果做数值排名。[S28–S30]

## 光学路线

| 技术 | 工程收益 | 代价与供应门槛 | 结论 |
|---|---|---|---|
| MicroLED + 波导 | 高亮度潜力、镜片外形好 | 外耦/入耦效率、色均匀、良率、专利和OEM供货 | 商业产品成熟，但本项目没有完整可采购光机资料 |
| MicroOLED + 小棱镜/组合器 | 面板公开资料较多，文本HUD可用 | 视野受眼盒限制、光学突出、日光对比、偏置电源 | H1优先询价路线；只买面板不能闭合系统 |
| LCoS | 成熟投影原理、高分辨率 | 光源、偏振、照明/成像光路和热量 | 不优先从零缩小到日常眼镜 |
| 大FOV birdbath / 折叠棱镜 | 高分辨率、大屏、开发相对便利 | 外形、透明度、外部供电 | 可做桌面显示替代，不作为H1首选 |
| DIY LCD+放大镜+分光片 | 零件容易买，适合原理验证 | 大体积、低效率、畸变和眼盒不确定 | D0台架可测试显示驱动，不能冒充成熟透明眼镜 |

检索的论文综述 [S36] 支持把采集、计算、交互和资源约束共同考虑，但论文不是本项目的性能验证。专利公开 [S35] 涉及近眼组合光学和眼盒结构，本项目未直接复制其权利要求方案，也未进行FTO分析。优先购买具有明确使用许可的完整光机；非商业源代码许可不解决第三方专利权。

## 调研后推翻的初始假设

没有沿用“选小面板+小电池便能做50g全功能眼镜”。实际核查发现：面板需要+5.5V/+1.8V/−4.5V、逻辑转换和光学装调；像素可视区域可能被裁切；离线录像需要持久存储；活动铰链和处方镜片有质量成本；SDK开放与硬件制造可复现是两个独立门槛。因此选择H1分层协同架构，并保留D0和现成HUD平台分别验证软件与光学体验。
