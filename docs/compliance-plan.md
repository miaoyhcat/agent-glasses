# 合规与专用验证计划

本项目没有认证证书。这里只确定需交给实验室评估的范围，不作可销售结论。认证范围必须以最终硬件、天线、固件、充电方式和销售地区为准。

| 范围 | 需要评估的资料与试验 |
|---|---|
| 电池包与运输 | IEC62133-2锂系统范围、UN38.3试验/摘要、保护设计、供应商追溯；不能用镍体系Part1替代锂系统Part2 |
| 电气与接触安全 | IEC62368-1适用性、电源/充电/故障能量、机械可达性、材料和接触温度 |
| 近眼光学 | IEC62471及适用眼镜显示标准范围，由光学实验室确认；按实际光谱、亮度、瞳孔位置和最坏软件状态测量 |
| 射频与EMC | FCC或目标市场的设备授权、人体附近暴露、模块天线/外壳改变、整机EMC与共存；模组证书不自动覆盖整机 |
| 欧盟产品 | RED、RoHS/REACH及适用隐私/网络安全要求；核对当前过渡安排与最终销售日期 |
| 中国/其他市场 | 由合格机构确认无线、电池、适用整机安全、标签和隐私规则，不猜测认证编号 |
| 防护与结构 | 若声明IP等级才按对应方法测试；汗液、铰链/充电触点、跌落、Rx片保持和电池冲击保持单独验证 |

一手索引包含IEC62368-1、IEC62471、IEC62133-2和欧盟RED官方范围。欧委会页面已在2026年更新网络安全与CRA的过渡安排；不能照搬旧文章的生效日期，也不能把已公布废止安排误读为任务执行日已无需要求。FCC/UNECE部分页面本次访问受限，未声称阅读了不可取得的完整条文。正式发布前由实验室复核适用版本与产品分类。[S41,S42,S49–S52]

专利公开与数据手册只用于技术调查，本项目未做完整自由实施分析。应向光机/无线/音频供应商明确商用许可、地区、组合使用和产品制造权。个人非商业源码授权不能替代这项工作。
