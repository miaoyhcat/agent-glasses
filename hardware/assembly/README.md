# D0装配约束

`d0-wiring.csv`从实际固件的`pins.h`导出。电源、地和模块内部稳压/逻辑电平不由GPIO表替代。全部模块必须共地；先核对各自数据手册和模块引脚图，再接信号。

GPIO19/20留给原生USB。GPIO35–37不可用作普通外设，因为选用N16R8的octal PSRAM占用。GPIO0需上拉，GPIO3作为SD_CS应在启动时被外部电阻保持不选中；GPIO45是启动配置脚，功放使能必须默认下拉，不能让外部模块在复位时拉高。GPIO43上电可能输出UART日志，SD在该阶段必须保持CS高、MISO高阻。不要同时接其他会驱动这些引脚的扩展板。

相机为带所需内部电源的3.3V DVP模块；裸传感器不是这种模块。麦克风选择I2S左声道，功放为I2S格式；二者共用BCLK/WS、分别使用输入/输出线，必须实际核对时钟与槽位。扬声器连接MAX98357A差分BTL输出，任何一端不得随意接地。

PRIVACY_READY应反映机械许可开关后的3.3V；CAMERA_GATE连接联锁板REQ。联锁板输出只控制相机电源，全部相机IO的断电高阻仍未闭合。不要以把PRIVACY_READY绑高或把LED删掉作为“调试通过”。

先在离体夹具和限流电源上逐外设验证。SD和SPI LCD共总线、独立CS，电平和上电默认态必须正确。不要把长杜邦线台架的临时稳定性当作H1的高速信号完整性证明。
