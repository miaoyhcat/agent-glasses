# H1可编辑结构夹具

`parameters.json`、`frame.scad`和`build_cad.py`为原创可编辑输入；`generated/`含STEP和STL。坐标x负为佩戴者左，z正为向耳后。光机方块是询价包络；不是供应商实际CAD。电子仓为65mm长度、20.4mm高度、8.6mm厚度，显著厚于普通无电子镜腿，舒适与美观仍需迭代。

三枚16×5.4mm候选电芯拟左侧两枚、右侧一枚；右侧MCU与相机放前端，左眼光机帮助配重。模型有基本盖板和紧固孔，但没有定版可折叠铰链、完整鼻托、镜片锁定、公差链、声腔、防汗密封和电池冲击保持。BREP有效不等于这些功能已经实现。

当前输出只用于断电布局/佩戴检查和装调夹具探索。光学基准需另外机加工/调整，不能由普通打印公差直接保证。0.8mm壁厚需制造商和强度试验确认；不把模型可打印当作日用可靠性。
